Description of Project-

Kannada Agricultural QA System Using RAG is a question answering pipeline built for Karnataka and Central Government agriculture scheme documents. Raw government PDFs were curated from scratch using text extraction into 81 clean Kannada text files. A complete RAG pipeline with cross-encoder reranking and FAISS dense retrieval is tested on five models (MuRIL, XLMRoBERTa, Sarvam-2B, IndicBARTSS, and Indic-GPT) with five metrics (BLEU, BERTScore-F1, Answer Similarity, Context Relevance, and Faithfulness).
